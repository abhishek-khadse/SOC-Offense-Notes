## Analysis

Alert generated by Kaspersky Security Center, ingested into QRadar after detecting a file associated with cryptocurrency mining activity. User qradar/user1 executed C:\Program Files\Qradar\file1.ext. Following execution, the endpoint security solution identified the threat as Trojan.JS.Miner.m. The QRadar custom rule engine rule "Qradar Xpro - Detected a cryptocurrency mining activity based on threat name" then generated the offense.

The threat name confirms the file is a Trojan associated with cryptocurrency mining. This kind of malware typically uses a lot of CPU/GPU resources and may connect out to mining pool infrastructure.

2. Terminate/quarantine file1.ext using Kaspersky Security Center or the endpoint solution.
3. Verify whether Trojan.JS.Miner.m was successfully quarantined or removed.
